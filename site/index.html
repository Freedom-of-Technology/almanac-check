Almanac Check

Are your domain's records still right?

Your almanac has a records file for each of your domains. Drop one here, and this page compares every line with what the internet sees right now.

Your records file

Drag the file onto this box, or choose it. It ends in .zone, or .txt for a file saved from GoDaddy or Cloudflare.

Your file stays on this computer. Nothing is uploaded. To check each record, this page asks Google's public lookup service about the names in your file, and asks the registry for your domain ending (such as .com) which DNS company runs your domain. Those are the same public questions any web browser or email server asks.

Almanac Check is free, from FreeOT. Its code is public on GitHub.
